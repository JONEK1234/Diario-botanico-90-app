# 🌿 Diario Botanico | Link Redirector PWA per Samuel

Questo pacchetto contiene un'applicazione **Progressive Web App (PWA)** completa ed autogestita, ottimizzata per essere caricata direttamente su **GitHub Pages**!

## 📱 Cos'è una PWA (Progressive Web App)?
L'applicazione non è un semplice file HTML scaricabile: è un'applicazione web installabile nativamente sul tuo telefono **iPhone, Android, tablet o computer** come se fosse una app scaricata dall'App Store o Google Play Store! 
- Funziona offline in assenza di rete.
- Può essere aggiunta alla Schermata Home per avviarla con un solo tocco senza mostrare le barre o i bordi del browser web safari/chrome.
- Possiede icone di lancio personalizzate ad altissima risoluzione ed una schermata di avvio (Splash Screen) integrata.

## 📦 Contenuto del Pacchetto ZIP:
1. `index.html`: La pagina web principale con logica intelligente di redirezione rapida ad 1 secondo e registrazione del Service Worker.
2. `manifest.json`: Il file di configurazione con metadati e colori per permettere l'installazione nativa sui dispositivi mobili.
3. `sw.js`: Il Service Worker offline che memorizza nella cache tutti i contenuti per garantire il caricamento ultra-veloce ed istantaneo anche in metropolitana.
4. `cover.jpg`: L'elegante immagine di sfondo scelta.
5. `icon-192.png` e `icon-512.png`: Le bellissime icone di avvio botanico per la schermata home del telefono.

## 🚀 Come installarlo su iPhone / Android:
Una volta caricati i file sul tuo indirizzo di **GitHub Pages**:
1. Apri il link del sito sul tuo browser mobile.
2. **Su iOS (Safari)**: Clicca sul pulsante di condivisione e seleziona **"Aggiungi alla schermata Home"**.
3. **Su Android (Chrome)**: Clicca sui tre puntini in alto a destra e seleziona **"Installa applicazione"** o **"Aggiungi a schermata Home"**.
4. L'app apparirà come icona sul tuo telefono; toccala per sperimentare il caricamento fulmineo e l'esperienza immersiva immersa nel verde!

## ⚙️ Come caricarlo gratis su GitHub Pages:

1. **Crea un nuovo repository pubblico** sul tuo account [GitHub](https://github.com) nominato ad esempio `diario-botanico`.
2. Estrai questo file **ZIP** sul computer.
3. Clicca su **"uploading an existing file"** sul sito GitHub e trascina tutti i 6 del pacchetto (`index.html`, `manifest.json`, `sw.js`, `cover.jpg`, `icon-192.png`, `icon-512.png`). Sottoscrivi cliccando **Commit changes**.
4. Vai su **Settings** > **Pages** e sotto "Branch" seleziona **main** (o master), quindi clicca su **Save**.
5. Attendi 45 secondi e il tuo link sarà online pronto da condividere con Samuel!
